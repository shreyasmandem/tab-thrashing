Operating systems · memory management · page replacement

Your browser is an operating system. Your tabs are its pages.

When RAM runs short, browsers discard background tabs. Switching back to one forces a reload: a page fault that costs a human seconds instead of a CPU microseconds. This lab replays tab-switch traces through six classic replacement policies and Denning's working-set model to measure which one predicts attention best, and how many live tabs a person needs before they start to thrash.

    Denning's working set W(t, Δ)

    When attention outgrows memory

    The working set is every tab touched in the last Δ switches. Wherever it rises above the frame budget, the session is in a thrashing zone: the user needs more tabs than the browser keeps alive, so reloads cluster.

    Do people behave like programs?

    Belady's anomaly

    More memory, more faults

    FIFO can fault more with more frames. The classic reference string shows it: 9 faults with 3 frames, 10 with 4. Stack algorithms such as LRU and OPT are immune. The table on the right counts how often each policy's fault count rises when a live tab is added.

    Study design

    From your browser to a fault curve

    The companion extension records tab switches and closes, never page content or full URLs. Hostnames are hashed by default. Export the log and drop it on this page with Load trace; every chart recomputes from your own data.

    Step 1

    Log

    A Manifest V3 extension listens to tab activate, create and remove events and stores them with timestamps. It also flags switches into tabs the browser had already discarded: real, measured page faults.

    Step 2

    Normalise

    Activations become a reference string. Closes free their frame. First visits are compulsory misses and are kept out of the refault rate.

    Step 3

    Replay

    Each policy runs at every frame count from 1 to 32, plus the working set across 21 window sizes. A Python port validates the JavaScript results against each other.

    Step 4

    Compare

    Find the knee with the Kneedle method, rank policies per user, test for Belady's anomaly, and optionally run the winner live with the extension's discard mode.

    t is seconds from the start. faulted marks a switch into a tab the browser had really discarded.

    Definitions

    Frame
    A tab the browser keeps alive in memory. k is the budget of live tabs.
    Refault rate
    Reloads of previously seen tabs per 100 tab switches. This is the study's human page-fault rate.
    Thrashing point
    The knee of the LRU refault curve: the farthest point below the chord between k = 1 and k = 32.
    Synthetic personas
    Seeded generators with anchor tabs, Zipf recency within phases, phase shifts, new-tab bursts and closes. They demonstrate the method; real logs replace them.
